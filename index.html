ƒ Champs calculés

Formule sur les sommes du tableau : [Champ], + − * / ^ ( ), ABS, SQRT, ROUND(x; 2), MIN, MAX, SI(cond; alors; sinon). [Nombre de lignes] = nombre de lignes de données. Division par zéro → cellule vide. Le champ apparaît ensuite dans la liste (bouton V).

▣ Groupes de valeurs
ou tous les

Crée un nouveau champ (dans la liste des champs) à glisser en Lignes, Colonnes ou Filtres : regroupez des valeurs (ex. plusieurs états civils) ou découpez un nombre en tranches (ex. l'âge).

Σ Mesures

Condition (facultative) : seules les lignes qui respectent tous les critères comptent. Plusieurs valeurs : séparez par « ; ».

Une mesure est un indicateur nommé, à poser dans Valeurs (bouton V), ex. « Nombre de femmes » (Gender = F), « % de femmes », « Âge moyen des femmes ». Elle peut aussi servir dans une formule de champ calculé.

Projets

Un projet regroupe tout votre tableau de bord : fichiers sources (jointures et champs calculés compris), onglets, graphiques, tuiles et mise en page. Il est enregistré automatiquement sur cet appareil. « Nouveau projet » repart d'un tableau de bord vide (un seul onglet vide) : chargez-y un autre fichier source. L'export crée un fichier .json qui contient les données de vos fichiers.

Aperçu et contrôle des données

    Jointures entre fichiers

    Une jointure rattache à chaque ligne d'une source (gauche) les colonnes d'une autre source (droite) qui ont la même clé (ex. code NIS ou nom de commune → province). Le résultat apparaît comme une nouvelle source « ⨝ … » recalculée à chaque actualisation des fichiers. Clés comparées sans casse ni accents (« 01001 » = 1001).

    Colonnes & fusion

    Chaque colonne est rattachée à un champ unifié. Deux colonnes qui portent le même nom (sans tenir compte de la casse, des accents ni de la ponctuation) sont fusionnées automatiquement. Pour fusionner des noms différents, saisissez le même champ unifié ; décochez « Inclure » pour exclure la colonne (aussi possible avec ⊘ dans la liste des champs). Les champs orange ne figurent pas dans toutes les sources.
